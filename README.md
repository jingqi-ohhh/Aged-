## 介绍
这是[Aged汉化包](https://modrinth.com/resourcepack/aged-jingqi_ohhh)的附属汉化包，对[Aged整合包](https://modrinth.com/modpack/aged)的Aged Guide Book里的内容进行简体中文翻译。

## 🔺注意：
本文件虽然以资源包形式下载，但是你要将它解压到版本文件夹下→resources文件夹下→aged文件夹中。
路径：.minecraft\version\Aged\resources\aged（有开版本版本隔离）

-----

## Introduction
This is an add-on localization pack for [Aged Chinese Translation](https://modrinth.com/resourcepack/aged-jingqi_ohhh). It provides Simplified Chinese translations for the content in the Aged Guide Book of [Aged modpack](https://modrinth.com/modpack/aged).

## 🔺Note:
Although this file is downloaded as a resource pack, you need to extract it into the version folder → resources folder → aged folder.
Path: .minecraft\version\Aged\resources\aged
