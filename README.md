## 介绍
本补丁为非官方汉化资源包，不包含整合包主体，用于给[Aged modpack](https://modrinth.com/modpack/aged)提供更全面的简体中文翻译。

汉化内容：
- 物品与提示文本（Lootr,EarlyStyle...）
- 进度与游戏提示（Better Dedert Temples...）
- 部分配置说明文本（Distant Horizon,Creeper Overhaul,Sodium and so on）
- 模组菜单界面（对有配置项模组的名称和描述进行了翻译，方便了解模组和在左上角检索模组，推荐你安装[通用拼音搜索](https://modrinth.com/mod/justenoughcharacters)快速检索模组）
